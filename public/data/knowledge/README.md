# PoE1 Craft Knowledge Base

Generated by `npm run build:knowledge` → `public/data/knowledge/`.

**Path of Exile 1 only.** Data comes from [RePoE](https://repoe-fork.github.io/) plus curated official lists. We do not invent crafts.

## Fully covered (from RePoE)

| File | Contents |
|------|----------|
| `mods-natural-prefix-suffix.json` | Natural item prefix/suffix + spawn weights |
| `mods-essence-only.json` | Essence-only mods |
| `mods-crafted-bench.json` | Crafting-bench crafted mod domain |
| `mods-unveiled.json` | Jun unveil outcomes |
| `mods-veiled-placeholders.json` | Veiled Prefix/Suffix placeholders |
| `mods-influence.json` | Shaper/Elder/Conqueror influence mods |
| `mods-delve.json` | Delve mods |
| `mods-eldritch-implicits.json` | Exarch / Eater implicits |
| `mods-enchantments.json` | Enchantments |
| `mods-jewels.json` | Abyss + cluster/affliction jewel prefix/suffix |
| `mods-flasks.json` | Flask prefix/suffix |
| `mods-remainder.json` | **All other RePoE mods** (unique item mods, base implicits, monster/area/map domains, …) |
| `essences.json` | Every essence + mod per item class |
| `fossils.json` | Every fossil + tag weights |
| `crafting-bench.json` | Every bench option (mods, sockets, enchants) + costs |
| `base-items.json` | Bases |
| `item-classes.json` / `tags.json` / `mod-types.json` | Supporting tables |

`coverage.json` reports `repoe_mod_total` vs `knowledge_mod_total` — these should match after a full rebuild.

## Curated official (not invented)

| File | Source |
|------|--------|
| `harvest-reforge-official.json` | [PoEDB Horticrafting](https://poedb.tw/us/Horticrafting) — Defence includes ES; **no** separate ES reforge |
| `metacrafts-official.json` | Bench metacrafts (SCBC/PCBC/etc.) |
| `cannot-roll-official.json` | Cannot-roll spawn constraints (caster/attack tags; legacy level-28) |
| `recombinators-official.json` | Unpredictable + Predictable operators; count table; cost currencies (amounts unpublished) |
| `../recombinator/3.29.json` | §85 empirical / sourced dataset (sources, sampleSize, confidence) |

## Missing / partial (see `coverage.json`)

- Full Harvest menu beyond reforges (add/remove sacred, resist swap, …)
- Recombinator exclusive-mod catalog (physics: `recombinators-official.json`; empirical: `/data/recombinator/3.29.json`)
- Allflame / Kingsmarch boat crafting (§51 unsupported in recombinator model)
- Beastcrafting recipe table
- League-specific craft operators (Scourge, Crucible, …) — mods exist, recipes not curated
